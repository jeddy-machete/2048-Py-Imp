# 2048 Project

This is an implementation of 2048 in python, using pygame

# Usage

As of 1/18/26, the Project runs inside the python shell

# Files

Project.py -> An earlier text-based version of the game running entirely in the shell.  Run game_loop() for usage.

graphics.py -> A graphics-based version of the game, run game_window() for usage.
Features WASD controls, Q to quit, R to reset, P to pause
